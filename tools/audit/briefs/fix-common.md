You are fixing VERIFIED audit findings in a production market-data system before its historical database is built (every session from 2022-05-27 to today, newest first, by stateless workers, for 64 US ETFs and large stocks). Several agents work in parallel, each in its own git worktree on its own branch; work ONLY in the worktree you are given, never in another worktree or in /home/diggz/vyreon-engine-worker or /home/diggz/vyreon-core's main checkout, and keep edits narrow (no reformatting, no moving code) so the branches merge.

The owner's priorities, in order:
 1. NO WRONG NUMBERS. A published value must be what its definition says, on a consistent basis. Where an input is missing, inconsistent, or its basis cannot be established, withhold the reading with an honest reason: never compute, fill, smooth or default (a silent zero or an assumed value is a defect).
 2. MATCH THE PUBLISHED STANDARD or market convention where one exists, exactly, and cite it in the decision record (OCC By-Laws and memos for contract adjustments; exchange calendars; standard day-count, compounding and option-pricing conventions; the standard definition of each technical indicator). Invent a rule only where none is published, and say so.
 3. An engine failure is an engine fault, never relabelled as a provider absence; and the reverse.
 4. One bad asset or input must not stop or corrupt the day for the others: contain it to the asset (or the reading), stated.
 5. Determinism: identical inputs give identical bytes.
Because nothing has been built yet, changing a method or science version label, or bytes on every day, is acceptable when it is the honest minimum; say exactly what changes on an ORDINARY day (all members listed, continuous archive, no adjustment, no fault), because real-day comparisons will be checked against your statement. Real data only (decision D-102): no synthetic or invented market data, even in unit tests. Tests use the frozen real slices under crates/*/tests/fixtures and /home/diggz/vyreon-engine/workspace/fixtures (set `VYREON_FIXTURES=/home/diggz/vyreon-engine/workspace/fixtures`), or encode real, cited facts.
